🏗️ Laravel-Brive Project Structure Map & Tree

🏗️ Architecture Overview

Laravel-Brive is a full-stack educational platform built with modern web technologies:

Backend
Laravel 10+ (PHP)
Frontend
Vue.js 3 + Inertia.js
Styling
Tailwind CSS
Database
MySQL/PostgreSQL
Authentication
Laravel Sanctum + Google OAuth
Permissions
Spatie Laravel Permission

📂 Main Directory Structure

🔧 Backend (Laravel)

app/ ├── Console/ # Artisan commands ├── Events/ # Event classes (LectureCompleted) ├── Exceptions/ # Custom exception handlers ├── Helpers/ # Utility helpers (BreadcrumbHelper, CourseProgressHelper) ├── Http/ │ ├── Controllers/ # API & web controllers │ ├── Middleware/ # Custom middleware │ ├── Requests/ # Form request validation │ └── Resources/ # API resources ├── Models/ # Eloquent models (User, Course, Quiz, etc.) ├── Policies/ # Authorization policies ├── Providers/ # Service providers ├── Services/ # Business logic services └── Traits/ # Reusable traits

🎨 Frontend (Vue.js)

resources/js/ ├── Components/ │ ├── Base/ # Reusable UI components (Button, Input, Card) │ └── Optimized/ # Complex components (StatsGrid, OptimizedTable) ├── Composables/ # Vue composables (useApi, useForm, useTable) ├── Pages/ # Inertia.js pages ├── Layouts/ # Layout components └── Services/ # Frontend API services

🗄️ Database Structure

database/ ├── migrations/ # Database schema migrations ├── seeders/ # Data seeders └── factories/ # Model factories for testing

⚙️ Configuration & Routes

config/ # Laravel configuration files routes/ ├── web.php # Web routes ├── api.php # API routes └── auth.php # Authentication routes

🎯 Key Models & Relationships

  • User → Enrollments, QuizAttempts, LectureProgress
  • Course → Sections → Lectures, Quizzes
  • Quiz → Questions → Answers
  • Enrollment → User ↔ Course relationship
  • Category → Courses organization

🎯 Architecture Principles

This structure follows Laravel best practices with clean separation of concerns, DRY principles, and optimized performance through Vue.js composables and reusable components. The codebase emphasizes maintainability, scalability, and developer experience.
